# Spicy Sugars Entertainment Website

Premium responsive static website for Spicy Sugars Entertainment.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub + Netlify
1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload all extracted files/folders, keeping the structure intact.
4. In Netlify, choose **Add new site → Import an existing project**.
5. Select the GitHub repository.
6. Build command: leave empty.
7. Publish directory: `/` (root).
8. Deploy.

## Hero video
The website works without a video because it includes a poster fallback. To use your own cinematic background, add:
`assets/videos/hero.mp4`

Recommended: MP4, H.264, 1920×1080, compressed for web.

## Important
Replace placeholder artist/gallery visuals and update the email/social links in `index.html` with the official Spicy Sugars contact details before launch.
